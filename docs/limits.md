# Limits and claim boundaries

PHI-SWARM is a **software simulation framework** (L0–L9).

## In scope

- Deterministic physics-generated Non-IID sensor windows
- Local CNN-BiLSTM PHM
- Federated aggregation with Ed25519-signed weight deltas only
- Integrity gate, trust fabric, decision and coordination layers
- Link-loss, seed-sweep, and adversarial injection experiments in simulation
- Reproducible audit trail verification

## Explicitly out of scope

- **L10 Hardware-in-the-loop (HIL)**
- **L11 Real flight / operational deployment**
- Claims of contested-spectrum link guarantees
- Claims of certified onboard flight software
- Guarantees against every possible adversarial model beyond the documented threat scenarios

Do not interpret simulation metrics as flight-validated performance.
