# Reproducibility

## Environment

```bash
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

Python 3.10+ recommended. No external datasets are required; telemetry is generated by `zerotwin/physics/engines.py`.

## Minimal verification

```bash
python scripts/validate_l5_l9.py
python scripts/run_phi_swarm.py --minutes 2 --round-interval 2
python scripts/verify_audit_trail.py
```

## Full suite

```bash
python scripts/run_full_validation.py
python scripts/run_seed_sweep.py
python scripts/run_link_loss_sweep.py
python scripts/export_paper_artifacts.py
python scripts/build_jais_evidence.py
```

## Seeds and determinism

Scripts that accept a seed use a fixed default when none is passed. Record the seed printed at the start of each run. Expected artifact shapes appear under `artifacts/example_*.json`.

## What not to commit

Runtime outputs under `zerotwin/results/` are gitignored. Commit only code, docs, and small examples under `artifacts/`.
